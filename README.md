אלה **קישורים לאתרי היצרנים**, לא חבילות התקנה שהועלו לחשבון Drive שלך. הורדת חלק מהתוכנות עשויה לדרוש הרשאות מנהל, חיבור אינטרנט או רישוי מתאים.

## ☁️ מה עושים עם תוכנות שהעלית ל־Google Drive?

- כל קובץ התקנה שצריך להיפתח במחשב תלמיד ללא חשבון Google אישי: ב־Drive לחץ **שתף → גישה כללית → כל מי שיש לו את הקישור → צופה**, ואז השתמש בקישור שהתקבל.
- אם מדיניות בית הספר אינה מאפשרת שיתוף ציבורי, יש להשתמש במנגנון הרשאות ארגוני מתאים או ב־SSD. **אל תשתף סיסמאות, פרטי תלמידים או קובצי ניהול פרטיים.**
- כדי שכל קובץ חדש יופיע לצוות **בלי לעדכן כל קישור בנפרד**, אפשר להשתמש בתיקיית Google Drive ייעודית שמשותפת לצפייה; יש לפרסם כאן את קישור התיקייה הציבורי לאחר הגדרתה. כרגע קישור תיקייה כזה עדיין לא הוגדר כאן.
